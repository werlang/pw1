# Sistema de Gerenciamento de Tarefas

Você deve implementar um sistema simples para adicionar e gerenciar tarefas usando HTML, CSS e JavaScript.

## Questões

- (3 Pontos) Questão 1: [Inserção de Tarefas](q1/README.md)
- (3 Pontos) Questão 2: [Renderização de Tarefas](q2/README.md)
- (3 Pontos) Questão 3: [Eventos de Conclusão e Exclusão de Tarefas](q3/README.md)
- (2 Pontos) Questão 4: [Juntando Tudo](q4/README.md)

A cada questão, você encontrará um arquivo `README.md` com as instruções detalhadas sobre o que deve ser implementado.

Cada questão é autocontida, ou seja, você pode resolver cada uma delas separadamente. No entanto, a questão 4 pede que você integre as funcionalidades das questões anteriores em um sistema coeso. Caso você prefira, pode resolver tudo dentro da questão 4.

A soma total de pontos possíveis é 11, mas a prova vale 10 pontos. Isto significa que você ganhará mais pontos por cada questão, mesmo que não possa tirar mais do que 10 pontos no total.
