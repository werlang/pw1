# Prova PW1 - P1 - Data Center de GPUs

Nesta prova, cada questão é autocontida. Isso significa que cada pasta `q1`, `q2` e `q3` possui seu próprio HTML, CSS e JavaScript.

Contexto geral: você está modelando partes de um sistema de data center responsável por cadastrar GPUs, registrar tarefas de processamento e controlar alocações.

Edite apenas o arquivo `script.js` de cada questão.

## Questões

* [Questão 01](q1) - Cadastro de GPUs
* [Questão 02](q2) - Alocação de tarefas em GPUs
* [Questão 03](q3) - Painel operacional e liberação de GPUs

## Peso de cada questão

- Cada questão vale 5 pontos.
- Você deverá escolher 2 questões para resolver, totalizando 10 pontos.
- A questão que não for escolhida deve ser deixada como está, sem alterações.
