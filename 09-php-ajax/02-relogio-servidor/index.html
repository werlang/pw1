Dica Didática: Os dois awaits do fetch()

Lembre-se da regra de ouro: precisamos de const resposta = await fetch(...) para esperar a chegada dos cabeçalhos HTTP, e de const dados = await resposta.json() para converter o corpo em texto para um objeto JavaScript.
